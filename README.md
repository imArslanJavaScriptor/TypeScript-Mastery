## 🚀 Getting Started

### Clone the Repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### Navigate to Project

```bash
cd TypeScript-Mastery
```

### Install TypeScript

```bash
npm install
```

### Run TypeScript Compiler

```bash
npx tsc
```

### Watch Mode

```bash
npx tsc --watch
```
